# Project Title
Sante Price Index

---

## Problem Statement
Farmers, traders, and consumers often do not have easy access to real-time vegetable price information. Prices fluctuate daily in mandis, and lack of transparency makes decision-making difficult. This project solves that by providing a simple mobile app with live price updates.

---

## Features
- Real-time vegetable price updates
- Digital price board display
- Market trends tracking
- Firebase integration for live data sync
- Simple and user-friendly UI
- Fast and lightweight performance

---

## Tech Stack
- Kotlin (Android Development)
- XML (UI Design)
- Firebase Realtime Database / Firestore
- Android Studio
